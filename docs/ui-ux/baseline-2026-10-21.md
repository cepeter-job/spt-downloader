## 2. Bahasa dan output yang tidak boleh mundur

Katalog [ui_copy.COPY](https://github.com/cepeter-job/spt-downloader/blob/ecbd9878aa732a379ba94ef848764f9815445003/spt_desktop/ui_copy.py) memuat **54 ID**, termasuk `app.bugreport`, ringkasan pilihan, ID disorot, petunjuk keyboard, pesan pencarian dan jumlah file. `app.credit` tetap dihapus. ID adalah kontrak teks, bukan jumlah widget atau bukti bahwa semua caption Pengaturan telah diselaraskan. Pengaturan masih memakai Cek Kredensial/Batalkan Cek/Hapus kredensial; jangan menyebut target Cek login/Hapus login sebagai revisi widget yang sudah selesai.

Normal dan masing-masing Model SPT literal tetap terpisah. PR #51 menambahkan template Badan tersanitasi untuk 12 lampiran referensi, tanpa menciptakan template Induk; pengecualian tampilan L10-B/L10-D tidak menghapus checkpoint atau proof workbook lama. Unifikasi non-Induk menghilangkan tampilan raw redundan tetapi mempertahankan sumber serta hitungan unresolved; DAFTAR-I memakai pecahan persentase numerik dan spacer kosong. Baca [kontrak output saat ini](../../AGENTS.md#output-contract), bukan deskripsi prototype lama, sebelum mengubah desain hasil.

PDF keuangan/auditan hanya ikut bila tautan baca yang didukung, byte, identitas, ukuran/hash dan custody lolos. Jangan menjanjikan semua lampiran atau mengartikan metadata sebagai PDF tersimpan. Log timeout privat-aman dari PR #55 bukan bukti bahwa timeout live historis sudah diperbaiki. Tidak ada hasil penerimaan akun baru dari revisi dokumentasi ini.

## 4. Bukti dan batas klaim

PR #53 membawa dialog Phase 2; [laporan Phase 2](../superpowers/reports/2026-10-20-ui-b-phase2-evidence.md) tetap menyebut kandidat, hasil dan batas aslinya. PR #58 merged pada `ecbd987`; [laporan performa](../superpowers/reports/2026-10-21-phase2-performance-evidence.md) mencatat 90 PNG native, 18 kasus layout, 18 close/Stop/terminal, enam pemeriksaan keyboard, serta sampel berpasangan. Filter median 1/100/1.000 SPT turun dari 77,94/79,27/85,15 ms menjadi 4,86/9,55/15,73 ms. Cancellation maksimum 73,33 ms adalah observasi sampel, bukan jaminan hardware. Sort tidak seluruhnya lebih cepat. Sepuluh sampel membuat p95 nearest-rank sama dengan maksimum.

Final-head PR #58 lulus [run 39538512382](https://github.com/cepeter-job/spt-downloader/actions/runs/39538512382): 3.377 tes Windows dan 456 portable, dengan suite saling tumpang-tindih; jangan menjumlahkannya sebagai kasus unik. Source/frozen, audit dan artifact readback lulus untuk head/tree yang dicatat di [PR #58](https://github.com/cepeter-job/spt-downloader/pull/58). Artifact final-head PR #58 adalah `12319261710`; head `b41b34a` dan merge `ecbd987` memiliki tree teruji `92ed772e8c76f3ba9c93e93ef0806d7621be3010`. Ini bukti historis runtime, bukan hasil pytest revisi dokumentasi sekarang, deployment, sertifikat aksesibilitas atau penerimaan semua akun.
