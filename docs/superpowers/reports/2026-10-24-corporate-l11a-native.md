## Supported boundary

The record must be the literal selected submitted CIT Rupiah View with
`?view=true`, a fresh owned Service-Worker-blocked SPA lifetime, preceding
observed Induk and explicit numeric `1` IsDeclareEntertainmentExpense in both
outer and current MainFormData. The literal model is Normal or `Amendment NNN`;
output metadata and leading zeroes remain unchanged. PreviousFormData must be
explicitly present and decode to null or an object with absent/null L11AFormData.
Any nonnull previous L11-A, including an empty object or array, stays unsupported.

All three actually loaded corporate/main/vendor provider hashes must match the
reviewed pins. The observer checks five exact component/ui-grid/p-table/form
chains, all group/header/span structures and the nested IV/IV.A owner before
and after the four owned paginators. It reads no body/footer values, input value,
checked state or reference cache, and does not force-fetch missing catalogs.

The active grid1/2/3/5 inventories use only their four inspected loadcit routes,
exact Data/TotalRecords payloads and the exact seven-field requests: selected
ReturnSheetRecordId, nonnegative integer First, `Rows = 10`, empty SortField,
integer `SortOrder = 1`, empty Filters and LanguageId id-ID. The fourth table is
embedded Facilities, with no invented route. Complete contiguous coverage,
including explicit empty inventories, is mandatory. Generic Index-grid schema
is unchanged. Each projected page index stays local to its own endpoint.

Closed reference admission supports five singleton GETs:
TYPE_OF_PROMOTION_COST, TANGIBLE_ASSET_INCLUDING_BUILDINGS,
NON_PERFORMING_LOAN_CATEGORY, DEDUCTION_METHOD and TYPE_OF_FULFILLMENT; plus only
the exact ordered DEDUCTION_METHOD,TYPE_OF_FULFILLMENT pair. Pair payloads may
reorder entries: unique literal types select the catalog while original
Payload/catalog/detail ordinals remain in provenance. Each compared catalog
type must have been requested by its exact endpoint. No arbitrary type lists,
reversed pair, checksum, query, body or new remote action is admitted.

Known selected-ID contradictions, changed original-byte snapshots and changed
per-query counts remain fatal before fallback, even without semantic bindings.
Count keys include endpoint and every query field except First. Successful
matching-type catalog content is compared across admitted transports before
overlap or semantic fallback, preserving JSON types, numeric lexemes, all
metadata, array order and duplicates. Same-URL raw snapshots remain stricter.
Malformed markers remain unsupported source shape; privacy, authorization,
locale, clock and lifetime contradictions retain their fatal checks.

L3 and L11-A validate their own auxiliary endpoint sets while the enclosing
adapter still requires declared requests and refuses unrelated responses.
Projected values retain original response sequence/container/path, typed source
tokens, business Index and cell-specific selected-label provenance. All twelve
IV.B fields remain canonical/checkpoint data and unresolved in the mapping Audit.
No new template slot, accounting format or footer is invented. The current-only
date, signed-zero, ordered 15-digit cost sum and final-clamp gates are unchanged.
