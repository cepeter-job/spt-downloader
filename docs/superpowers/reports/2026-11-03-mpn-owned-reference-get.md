## Scope and diagnosis

The preceding MPN date-clear repair reached an original selected-scope list
whose sole filter was IsCancelled/equals/0. The later parent binding failed
because three displayed labels had no captured original catalog inventories.
The pinned Accounting service can satisfy reference loads from its existing
cache without issuing the combined catalog request. This source finding does
not establish the live contents of any cache; none were read or cleared.

The operator explicitly approved one fixed four-type id-ID GET and its bounded
implementation, followed by review, CI, merge and package delivery. See the
[approved design](../specs/2026-11-03-mpn-owned-reference-get-design.md).

## Live diagnostic experiment

One exact-endpoint GET returned HTTP 200 in 1025.1 ms and 5,742,869 original
bytes. It contained exactly the four expected groups, valid checksum fields,
no explicit locale contradictions and no duplicate codes. All seven parent
binding fields matched on all ten displayed original-response rows after
applying the original labels. The retained Document and literal ledger stayed
current. No Detail action, cache access, alternate request or retry occurred.

Original bytes and the sanitized receipt remain outside Git in the local
private investigation directory. This manual page had no controlling Service
Worker; the experiment does not certify the product's blocked-context gate,
full capture, publication, or build-matched live acceptance.

## Implementation and regression evidence

The adapter drains pending original sources first. It only acquires when every
current parent mismatch is a reference label whose original catalog inventory
is missing. The final strict comparison and inspected Detail action gates
remain. Empty inventories and sufficient raw-code bindings add no GET.

The acquired request uses the existing owned context, exact fixed endpoint,
both loaded pins, retained Document/attempt, original selected-scope unfiltered
list, no redirects/retries, a five-second deadline and eight-MiB acceptance
budget. Stop and sticky safety failures retain precedence. Buffered response
retrieval and disposal do not establish a hard process-memory or cleanup
wall-clock ceiling; responses after the acceptance deadline are refused.

Private original-byte evidence distinguishes observed-get-v1 from
adapter-get-v1. Legacy missing origin remains readable. Unknown explicit
origins and origins on list/detail evidence are refused before held-byte
projection/publication.
